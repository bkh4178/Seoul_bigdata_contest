# Seoul Space Index
서울시 빅데이터 기반 모아 센터 입지 적합도 분석 프로젝트

## 1. Overview
본 프로젝트는 서울시 빅데이터를 활용하여 유휴공간 활용 가능성과 지역 수요를 함께 고려한 입지 적합도를 분석하는 것을 목표로 한다.  
단순 현황 정리에 그치지 않고, 다양한 공간·인구·시설 관련 지표를 통합하여 후보 지역의 우선순위를 정량적으로 도출하고자 한다.

## 2. Background
도시 내 유휴공간 및 저활용 공간은 복지, 생활 SOC, 지역 활성화 측면에서 중요한 활용 가능성을 가진다.  
하지만 실제 입지 선정 과정에서는 지역별 특성과 수요를 종합적으로 반영한 정량적 기준이 부족한 경우가 많다.  
본 프로젝트는 서울시 빅데이터 캠퍼스 데이터를 바탕으로 이러한 문제를 데이터 기반으로 해석하고, 정책적 활용 가능성이 있는 입지 평가 체계를 구성하는 데 목적이 있다.

## 3. Objectives
- 지역별 특성을 반영할 수 있는 입지 평가 지표 설정
- 데이터 전처리 및 공간 단위 통합
- 지표별 점수 산출 및 종합 스코어링
- 최종 후보지 우선순위 도출
- 지도 기반 시각화 및 결과 정리

## 4. Data
본 프로젝트는 서울시 빅데이터 캠퍼스 및 기타 공공 데이터를 활용하여 진행 중이다.  
현재 데이터 수집 및 확장과 함께 분석에 필요한 변수 체계를 지속적으로 보완하고 있다.

활용 데이터 예시는 다음과 같다.
- 서울시 공간데이터
- 인구 및 생활 관련 데이터
- 시설 입지 데이터
- 부동산/생활 인프라 관련 데이터
- 행정구역 및 매핑용 기준 데이터

## 5. Project Status
현재 프로젝트는 다음과 같은 흐름으로 진행 중이다.
- 분석 주제 및 평가 방향 설정
- 활용 가능한 데이터 검토 및 확보
- 주요 지표 정의 및 스코어링 로직 설계
- 데이터 전처리 및 공간 단위 매핑 진행
- 시각화 및 결과 정리 방향 검토

※ 데이터와 분석 로직은 프로젝트 진행에 따라 계속 업데이트될 수 있다.

## 6. Directory Structure
```text
.
├── code/   # 전처리, 분석, 시각화 코드
├── data/   # 원천 데이터 및 가공 데이터
└── doc/    # 문서, 회의자료, 정리 파일
```


## 7. Expected Output
- 입지 평가 지표 정리
- 지역별 스코어 산출 결과
- 우선 검토 지역 도출
- 지도 기반 시각화 자료
- 공모전 제출용 문서 및 발표 자료

## 8. Notes
본 저장소는 서울시 공모전 프로젝트 진행 과정에서 작성된 코드, 데이터, 문서를 정리하기 위한 목적으로 관리된다.
프로젝트 특성상 데이터 구조와 분석 방식은 지속적으로 수정·보완될 수 있다.

# 서울시 주거취약지역 기반 모아센터 입지 우선순위 분석

서울시 행정동 단위의 주거 취약성, 정책 수요, 공급 공백을 종합해 모아센터 추가 입지 우선순위를 도출한 공모전 분석 프로젝트입니다.

본 프로젝트는 단순히 취약한 지역을 찾는 데서 끝나지 않고, 현재 모아센터 접근성이 낮고 정책 수요가 높으며 기존 공급이 부족한 지역을 함께 고려해 실제로 "어디에 먼저 추가 배치하는 것이 타당한가"를 데이터 기반으로 판단하는 것을 목표로 합니다.

---

## 1. 프로젝트 개요

서울시는 고령층, 저소득층, 장애인 등 다양한 취약계층을 대상으로 한 생활지원 인프라를 운영하고 있지만, 행정동별 주거환경과 생활 여건, 기존 시설 접근성은 균등하지 않습니다.

이에 따라 본 프로젝트에서는 다음 질문에 답하고자 했습니다.

> "서울시 내에서 모아센터가 추가로 필요할 가능성이 높은 행정동은 어디인가?"

이를 위해 행정동 단위의 주거 취약성 지표를 구축하고, 기존 모아센터 위치와의 거리 기반 접근성 분석, 정책 수요 지표, 공급 결핍 지표를 함께 활용했습니다.

---

## 2. 분석 프레임워크

본 분석은 크게 세 가지 축으로 구성됩니다.

### 2.1 주거취약성 지표 (HVI)

행정동별 주거 취약성을 파악하기 위해 다음 요소를 활용했습니다.

- 연립·다세대 주택 임대 예측시세 기반 저가 주거 비율
- 건축물대장 기반 노후 주택 비율
- 건축물대장 기반 주거 밀집도

이를 통해 단순히 "집값이 낮은 지역"이 아니라, 저가 주거, 노후도, 밀집도가 함께 나타나는 지역을 주거취약지역으로 해석했습니다.

### 2.2 정책 수요 지표

모아센터의 정책적 필요성을 반영하기 위해 행정동 단위의 취약계층 및 생활 여건 관련 지표를 활용했습니다.

활용한 주요 지표는 다음과 같습니다.

- 고령층 관련 지표
- 장애인 관련 지표
- 저소득 관련 지표
- 생활환경 관련 지표
- 재난·안전 관련 지표
- 범죄 취약성 관련 지표

각 지표는 행정동 단위로 정리한 뒤, 정책 수요가 높은 지역을 식별하는 데 사용했습니다.

### 2.3 공급 공백 및 접근성 지표

기존 모아센터의 위치를 기준으로 행정동별 접근성을 계산했습니다.

분석의 핵심은 다음과 같습니다.

- 기존 모아센터 위치가 있는 행정동은 후보지에서 제외
- 행정동 대표점과 기존 모아센터 간 거리 계산
- 모아센터 접근성이 낮은 행정동 식별
- 추가 입지 시 접근성 개선 효과를 시뮬레이션

이를 통해 단순히 취약성이 높은 지역이 아니라, 현재 시설 접근성이 낮아 공급 공백이 존재하는 지역을 후보지로 선별했습니다.

---

## 3. 후보지 선정 기준

최종 후보지는 다음 조건을 기반으로 필터링했습니다.

1. 기존 모아센터가 위치한 행정동 제외
2. 저층주거지가 없는 행정동(HVI=0) 제외
3. 최종 점수, 정책 수요, 공급 결핍 지표가 부족한 행정동 제외
4. 정책 수요가 낮은 하위 10% 행정동 제외

이후 남은 행정동을 대상으로 최종 점수를 산출해 모아센터 추가 설치 우선순위를 도출했습니다.

---

## 4. 시뮬레이션 설계

후보지 선정 이후에는 추가 모아센터 배치 시나리오를 구성해 접근성 개선 효과를 검토했습니다.

시나리오는 S0~S4 총 5개로 구성됩니다.

- **S0**: 기존 14개소 (기저선)
- **S1**: 후보 풀에서 랜덤 14개 추가, 1,000회 반복 (방법론적 비교 기준)
- **S2**: 수요지수 상위 14개 배치 (단일지표 비교)
- **S3**: 최종지수 상위 14개 배치, 기존 센터 행정동만 제외 (MCI 단독 최적화)
- **S4**: 기존 센터 중복 배제 + HVI 필터 + 인접 파급효과 고려 (최종 제안)

시뮬레이션의 목적은 다음과 같습니다.

- 기존 모아센터 체계에서 접근성이 낮은 행정동 확인
- 후보지 추가 배치 이후 접근성 개선 여부 확인
- 단순 점수 기반 선정이 실제 공간적 개선으로 이어지는지 검증
- 랜덤 배치 결과(S1)와 비교해 제안안(S4)의 상대적 효과 확인

특히 단순히 "취약한 곳을 골랐다"는 수준에 머무르지 않고, 추가 배치가 실제로 접근성 개선을 만들어내는지를 확인하는 데 초점을 두었습니다.

## 6. 레포지토리 구조

현재 레포지토리는 분석 진행 과정에 맞춰 비교적 단순하게 구성되어 있습니다.

- `geonho/code/`: 지표 구축, 후보지 필터링, 시뮬레이션, 시각화 코드
- `geonho/data/`: 분석 과정에서 사용한 데이터 및 중간 산출물
- `geonho/docs/`: 분석 문서 및 참고자료
- `Index_data/`: 행정동 단위로 정리된 주요 지표 데이터
- `.gitignore`: 로컬 환경 및 불필요 파일 제외 설정
- `README.md`: 프로젝트 설명 문서

분석 목적상 코드 구조를 엄격한 패키지 형태로 분리하기보다는, 지표 구축, 후보지 필터링, 시뮬레이션, 시각화 순서에 맞춰 작업 파일을 관리했습니다.

## 7. 주요 스크립트

### `build_candidate_pool.py`

모아센터 추가 입지 후보지를 생성하는 스크립트입니다.

주요 기능은 다음과 같습니다.

- 기존 모아센터 위치 행정동 제외
- HVI=0 행정동 제외
- 최종 점수 및 주요 지표 결측 행정동 제외
- 정책 수요 하위 행정동 제외
- 후보지 목록 생성
- 필터링 로그 저장

출력 파일 예시는 다음과 같습니다.

- `data/output/candidate_pool.csv`
- `data/output/filter_log.txt`

### `simulation.py`

후보지 추가 배치에 따른 접근성 개선 효과를 검토하는 시뮬레이션 코드입니다.

주요 기능은 다음과 같습니다.

- 기존 모아센터 기준 접근성 계산 (S0)
- S1~S4 시나리오별 접근성 변화 계산
- 시나리오별 개선 효과 비교
- 랜덤 배치(S1) 1,000회 반복 분포와 최종 제안(S4) 비교

### `최종시각화_0421.py`

최종 분석 결과를 지도 및 그래프 형태로 시각화하는 코드입니다.

주요 기능은 다음과 같습니다.

- 행정동별 지표 시각화
- 최종 후보지 지도화
- 접근성 개선 결과 시각화
- 발표 및 보고서용 이미지 산출

## 8. 데이터 안내

다만 일부 데이터는 반출 정책상 원본 데이터 공개가 제한될 수 있습니다. 따라서 본 레포지토리에는 분석에 필요한 가공 지표, 코드, 문서 중심으로 정리했습니다.

사용한 주요 데이터 범주는 다음과 같습니다.

- 서울시 건축물대장 정보 (공공데이터포털)
- 행정동 단위 인구 및 취약계층 관련 지표
- 생활환경 및 안전 관련 지표
- 기존 모아센터 위치 정보
- 서울시 행정동 경계 데이터 (2025년 2분기)

## 9. 분석 방향 요약

> 주거취약성, 정책 수요, 공급 공백을 함께 고려해 모아센터 추가 설치가 필요한 행정동을 도출하고, 시뮬레이션을 통해 제안 후보지가 실제 접근성 개선에 기여하는지 검증한다.

이 프로젝트는 특정 지표 하나로 취약지역을 단정하지 않고, 주거환경, 수요, 기존 공급의 불균형을 함께 반영했다는 점에 초점을 둡니다.

## 10. 한계

본 분석에는 다음과 같은 한계가 있습니다.

- 행정동 대표점을 기준으로 거리를 계산했기 때문에 실제 보행 경로나 대중교통 접근성과는 차이가 있을 수 있습니다.
- 일부 지표는 데이터 반출 및 가용성 문제로 인해 가공 지표 형태로 활용했습니다.
- 지표별 가중치는 정책적 해석 가능성과 공모전 분석 목적에 맞춰 설정했으며, 절대적인 정책 기준은 아닙니다.
- 모아센터의 실제 설치 가능성은 부지 확보, 예산, 행정 절차 등을 추가로 검토해야 합니다.
